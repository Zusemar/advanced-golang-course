# Поправки к лекции 2 (каналы и select)

В записи лекции ошибки поправлены плашками, у каждой есть код [L2-NN]. Здесь подробные
разборы для плашек со словами «Подробно в репозитории курса».

Как читать разбор: что было сказано, как правильно, механизм в коде runtime go1.27.1 (со
ссылками), проверка замером (числа с машиной, на которой они получены), что не проверено и
как проверить самому. Картинки лежат в `assets/`, команды запускаются из папки `demos` (для L2-02 из
`l2-02-probe`, для L2-08 из `l2-08-probe`).

- [L2-02](L2-02.md). Что лежит в канале: значения в слотах, кольцевой буфер под c.lock.
- [L2-08](L2-08.md). Кто будит select: гонку решает CAS по g.selectDone, а не планировщик.
- [L2-11](L2-11.md). Куда уходит время select: сортировка адресов дороже локов.
