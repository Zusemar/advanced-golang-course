# Поправки к практике 2 (fan-in, nil-каналы и drain)

В записи практики ошибки поправлены плашками, у каждой есть код [P2-NN]. Здесь подробные
разборы для плашек со словами «Подробно в репозитории курса».

Как читать разбор: что было сказано, как правильно, почему (код компилятора и runtime go1.27.1
со ссылками), замер (числа с машиной, на которой они получены), что не проверено и как проверить
самому. Картинки лежат в `assets/`, команды запускаются из папки `practice`.

- [P2-03](P2-03.md). Однонаправленный канал: запрещает компилятор, а машинный код тот же.
- [P2-05](P2-05.md). Горутина на вход или один select: горутины быстрее при любом числе входов, и разрыв растет.
